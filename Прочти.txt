TaskShelf для Mac с процессором Apple Silicon

Откройте TaskShelf.app. Панель появится на основном дисплее вплотную к нижнему краю экрана. Если Dock тоже закреплён внизу, он может перекрывать панель.

• Для каждого доступного окна панель показывает широкую кнопку с заголовком. Без разрешения «Универсальный доступ» показана одна широкая кнопка на приложение с обнаруженным окном. После закрытия последнего окна остаются только закреплённые значки.
• Правый клик по иконке → «Закрепить» или «Открепить». Правый клик по пустому месту панели открывает меню TaskShelf. Чтобы закрепить закрытое приложение, выберите в нём «Закрепить приложение…».
• Ширина кнопки зависит от заголовка и ограничена 204 пунктами. У активной кнопки скруглённый фон и голубая черта под значком. У остальных открытых окон черта короче и белая.
• Кнопка  открывает «Пуск». Слева можно найти и запустить программу, справа — открыть закреплённую. Чтобы закрепить или открепить программу, нажмите на неё правой кнопкой. Кнопка «+» позволяет выбрать приложение из другой папки. Кнопка питания внизу открывает команды перезагрузки и выключения.
• Справа на панели — текущая раскладка, Wi-Fi, звук, аккумулятор (при наличии) и часы. По умолчанию под временем видна дата. Чтобы скрыть её, нажмите правой кнопкой по пустому месту панели и снимите галочку «Показывать дату». Нажмите на код раскладки, чтобы выбрать источник ввода.
• У самого правого края панели, за часами, находится узкая область «Показать рабочий стол». Она подсвечивается при наведении. Нажмите, чтобы свернуть видимые окна, и ещё раз, чтобы вернуть их. Для окон, которые нельзя свернуть, панель скрывает приложение.
• TaskShelf открывает свои панели Wi-Fi, звука и аккумулятора над нажатым значком. В панели Wi-Fi можно выбрать сеть или перейти на вкладку Bluetooth, чтобы включить или выключить Bluetooth, посмотреть подключённые устройства и открыть настройки. В панели звука можно изменить громкость и устройство вывода. Список раскладок и календарь также открываются снизу. Из календаря можно открыть системный Центр уведомлений. После выдачи «Универсального доступа» TaskShelf также ищет значки приложений, доступные через Accessibility. Стрелка ⌃ раскрывает сетку значков сторонних приложений. Наведите указатель на значок, чтобы увидеть название, или нажмите, чтобы открыть меню приложения.
• Клик по закреплённой иконке запускает закрытое приложение. Клик по открытому приложению выводит окно вперёд. Повторный клик сворачивает активное окно. При следующем выборе окно восстанавливается.
• Наведите указатель на кнопку открытого окна, чтобы увидеть его миниатюру над панелью. В меню TaskShelf выберите «Разрешить превью окон…» и разрешите TaskShelf запись экрана. На кнопке приложения без доступа к отдельным окнам показывается его переднее доступное окно.
• Чтобы закрыть конкретное окно, нажмите правой кнопкой по его кнопке на панели и выберите «Закрыть окно». Если приложению нужно сохранить изменения, оно покажет обычный запрос.
• Если окон несколько, выберите нужное по заголовку в меню правого клика. Там же «Развернуть / вернуть размер» заполняет рабочую область и освобождает место для панели.
• Если для двойного клика по заголовку выбрано «Заполнить», TaskShelf оставляет снизу место для панели. Для этого включите «Универсальный доступ».
• Для управления отдельными окнами в меню TaskShelf выберите «Разрешить доступ к окнам…» и включите TaskShelf в разделе «Универсальный доступ». Пока доступ не выдан, клик скрывает или показывает приложение целиком.
• Пункт меню TaskShelf «Запускать при входе» включает автозапуск. При необходимости macOS предложит подтвердить его в системных настройках.
• Для выхода выберите «Завершить панель» в меню TaskShelf.

Для самостоятельной сборки запустите bash build.sh в папке с исходниками. Сборка использует имеющийся сертификат Apple Development, если он один. Для явного выбора задайте TASKSHELF_SIGN_IDENTITY. При смене подписи macOS может запросить «Универсальный доступ» ещё раз. Панель работает с обычной защитой macOS, системные модули ей не нужны.
